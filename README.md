# 💌 Gift Game Bot

Telegram-бот, который открывает персональную игру-открытку — интерактивный подарок для второй половинки, реализованный как Telegram Mini App.

## ✨ Что это

Бот отправляет пользователю ссылку на мини-игру внутри Telegram. Игра персонализируется под конкретную пару: фото, имена, сюжет и диалоги подбираются индивидуально.

## 🧱 Стек

- Python
- python-telegram-bot
- Telegram Mini Apps

```

```

## 🚀 Запуск

1. Клонируй репозиторий
   ```bash
   git clone <repo-url>
   cd <repo-name>
   ```
2. Установи зависимости
   ```bash
   pip install -r requirements.txt
   ```
3. Настрой переменные окружения (токен бота и т.д.) — см. в начале `katya_miniapp_bot.py`
4. Запусти бота
   ```bash
   python katya_miniapp_bot.py
   ```

## 💡 О проекте

Изначально сделан как персональный подарок, сейчас развивается как основа для персонализированных игр-подарков на заказ.
